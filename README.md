# Pandabie

![Pandabie Front Render](https://github.com/user-attachments/assets/ff5e91d5-1f60-4f92-a546-3859df206c76)

Pandabie is a tiny motion-controlled digital pet panda

## What it is

Pandabie is a small pet panda designed to sit on your desk and react to his environment.

The board includes a microcontroller, display, motion sensor, and environmental sensor in a compact PCB design.

## Why?

I designed Pandabie as my first week project for Half Life

## Software

[`firmware/`](firmware/) contains one Arduino IDE sketch for the XIAO ESP32C3, with all of Pandabie's firmware

## Repository contents

- `pandabie/` - KiCad source files and gerber files
- `BOM.md` - bill of materials for Pandabie
- `JOURNAL.md` - journal and timelapse entries for Half Life
- `firmware/` - Arduino IDE code
